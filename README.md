A simple, classic Tetris game built with HTML, CSS, and JavaScript.
Play directly in your browser — no installs needed.

 Play the Game

Just open the GitHub Pages link in the repository description.

 Controls
Space → Start game
Arrow Left → Move left
Arrow Right → Move right
Arrow Down → Drop faster
Arrow Up → Rotate piece
 Features
Classic Tetris gameplay
Next-piece preview
Score + row tracking
Increasing difficulty over time
Background music 🎵
Responsive layout for different screen sizes
 Project Files
index.html – Main game file
stats.js – FPS/performance stats
music.mp3 – Background music
texture.jpg – Game board texture
 Notes
